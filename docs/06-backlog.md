# Что не реализовано

Сверка кода с `PRD.md` §8 (функциональные требования) и §10 (нефункциональные), проведённая
по исходникам, а не по документации. Файл живёт как рабочий список: пункт закрывается — ставится
отметка и дата.

**Отметки:** `[ ]` не сделано · `[~]` частично (в скобках — чего именно не хватает) · `[x]` сделано.

**Приоритеты PRD:** `P0` — MVP, `P1` — v1.0, `P2` — потом.

Порядок работы: сначала ядро фаз 0–1 (симуляция и канвас MVP), потом телеметрия и платформа,
в последнюю очередь P2. Пункт считается закрытым, когда есть код, тест и правка документации.
